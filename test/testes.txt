TESTES DA API - Circuito Terê-Verde

Como testar:
1. Rodar: npm install
2. Rodar: npm start
3. Abrir no navegador:

Teste 1 - API no ar
GET http://localhost:3000/

Teste 2 - Listar Parques
GET http://localhost:3000/api/parques
Deve retornar lista com PARNASO e outros

Teste 3 - Listar Trilhas
GET http://localhost:3000/api/trilhas
Deve retornar Pedra do Sino, Cartao Postal, etc

Resultado: Todos os testes manuais passaram
