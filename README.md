# Circuito Terê-Verde - Trilhas e Parques

Projeto MVP Back End do Curso de Análise e Desenvolvimento de Sistemas - Unifeso - Teresópolis RJ

## Finalidade
Este projeto é o MVP (Produto Mínimo Viável) da disciplina de Back-End. 
O objetivo é criar um Back-End, construído em no Framework Django, contendo os dados com ORM nativo do django, para criação de tabela no banco de Dados, API para o Circuito Terê-Verde, para permitir aos usuários informações sobre parques e trilhas de Teresópolis, que abrange o Parque Nacional da Serra dos Órgãos, Parque Municipal das Montanhas de Teresópolis e Parque Estadual dos Três Picos, como Pedra do Sino, Cartão Postal e Pedra do elefante, facilitando o acesso a informações de turismo ecológico.
